SAE Portfolio : Conception et Développement d'un Site Web Professionnel

Conception et développement complet de ce portfolio — présentation des compétences techniques, projets académiques et profil d'étudiant R&T. Design Terminal/Hacker, HTML/CSS/JS vanilla, sans framework.

Rôle : Développeur Frontend Nov – Déc 2024 HTML5 / CSS3 / JS

1. Le Défi — Synthétiser son Parcours

Me présenter à des recruteurs sans passer par un CV Word comme tout le monde. L'idée : un site qui ressemble à ce que je suis — quelqu'un qui passe ses journées dans un terminal.

Objectifs

  • Design Terminal — Identité graphique dark, monospace, style console hacker.
  • Responsivité — Optimal sur PC, tablette et mobile.
  • Structure — Accueil, Compétences, Projets (études de cas), Contact.
  • UX — Animations Scroll Reveal, navigation claire, cursor personnalisé.

2. La Solution Technique

Application Web statique développée en vanilla HTML/CSS/JS, sans framework — pour démontrer une maîtrise complète du trio fondamental.

  • HTML5 — Structure sémantique (header, main, section, article).
  • CSS3 — Variables CSS, Flexbox/Grid, scanlines, animations keyframes.
  • JavaScript Vanilla — IntersectionObserver (Scroll Reveal), typer effect, header scroll.
  • JetBrains Mono — Police monospace choisie pour l'identité terminal.
  • Responsive Design — Media queries mobile-first.

Palette Terminal

:root {
  --bg:      #080808;  /* Noir profond */
  --accent:  #00ff41;  /* Vert terminal */
  --accent2: #00e5ff;  /* Cyan clés JSON */
  --text:    #b8ffb8;  /* Vert pâle texte */
  --font:    'JetBrains Mono', monospace;
}

3. Résultats & Compétences

  • HTML/CSS/JS pur — Pas de framework pour cacher ce qu'on ne sait pas faire. Si ça marche, c'est parce que je l'ai écrit.
  • Identité cohérente — Même police, mêmes couleurs, même logique sur toutes les pages. Un détail qui demande plus de rigueur qu'il n'y paraît.
  • Tout documenté — Chaque projet a son étude de cas. Ce portfolio est aussi une archive de ce que j'ai appris.
  • Rapide par défaut — Aucune dépendance externe, pas de bundle à charger. Le navigateur affiche, c'est tout.
